# FF11 Warp Finder

FINAL FANTASY XI（FF11/FFXI）の、とてもとてもたくさんあるワープ移動先を探すためのツールです。

GitHub Pagesで公開中: 
🔗 https://klarheit-git.github.io/ff11-warp-finder/

## 概要

FF11にはホームポイント、サバイバルガイド、ユニティワープなど、多数のワープ手段があります。

「目的地に行くにはどのワープを使えばいいんだっけ？」というときに、目的のエリアから利用できるワープを検索できることを目指しています。
